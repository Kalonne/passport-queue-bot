# Автоматичний моніторинг черги ДП «Документ» (Мюнхен)

Цей Space створений для цілодобового моніторингу черги Паспортного сервісу в Мюнхені (Heinrich-Wieland-Straße 5) на послугу:
**«Закордонний паспорт та (або) ID-картка»**.

## Як це працює:
1. Контейнер працює у фоні 24/7.
2. Кожні 60 секунд перевіряє наявність вільних слотів.
3. Щойно з'являється місце — надсилає скріншот та посилання в Telegram.
4. На головній сторінці відображається живий статус і системні логи.
