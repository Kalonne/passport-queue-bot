# Моніторинг електронної черги ДП «Документ» (Мюнхен)

Автоматичний скрипт для перевірки наявності вільних місць у Паспортний сервіс (м. Мюнхен, Heinrich-Wieland-Straße 5) на послугу:
**«Закордонний паспорт та (або) ID-картка»**.

Коли з'являються вільні слоти (зникає повідомлення *"Вибачте, на даний момент всі місця зайняті!"* або API повертає доступні дні), бот надсилає повідомлення та скріншот у Telegram.

---

## 📁 Структура проєкту

* `check_queue.py` — основний Python-скрипт (використовує Playwright, обходить Cloudflare захист, перевіряє чергу, робить скріншот і надсилає в Telegram).
* `.github/workflows/check_queue.yml` — конфігурація для автоматичного запуску на GitHub Actions за розкладом (кожні 10 хвилин) або вручну.
* `requirements.txt` — список бібліотек Python.
* `run_local.bat` — скрипт для запуску на власному комп'ютері в нескінченному циклі (кожні 60 секунд).

## 🚀 Варіант 1: Завантаження та робота на GitHub Actions

### Крок 1. Створіть репозиторій на GitHub
1. Зайдіть на [github.com](https://github.com) і створіть новий репозиторій (рекомендується вибрати **Private**, щоб ваш бот і логи були приватними).

### Крок 2. Додайте секрети (Secrets) у GitHub
1. У вашому новому репозиторії перейдіть у **Settings** → **Secrets and variables** → **Actions**.
2. Натисніть **New repository secret** і додайте два секрети:
   * Назва: `TELEGRAM_BOT_TOKEN`
     Значення: `8956789904:AAFRFy1WlV3gzs4aj8lpq7gSFnBtQjN7si8`
   * Назва: `TELEGRAM_CHAT_ID`
     Значення: `838131789`

### Крок 3. Завантажте файли в репозиторій
Відкрийте термінал у папці проєкту та виконайте команди:
```bash
git init
git add .
git commit -m "Initial commit for passport queue bot"
git branch -M main
git remote add origin https://github.com/ВАШ_ЛОГІН/ВАШ_РЕПОЗИТОРІЙ.git
git push -u origin main
```

### Крок 4. Запуск та перевірка
* Перейдіть на вкладку **Actions** у вашому GitHub-репозиторії.
* Виберіть воркфлоу **Check Passport Queue**.
* Натисніть **Run workflow**, щоб перевірити ручний запуск.
* Надалі він запускатиметься автоматично за розкладом (`cron: '*/10 * * * *'`).

> ⚠️ **Важлива примітка щодо лімітів GitHub Actions:**
> * GitHub Actions надає **2000 безкоштовних хвилин на місяць** для приватних репозиторіїв.
> * Кожен запуск триває ~1.5 хвилини. Якщо запускати кожні 10 хвилин, безкоштовні хвилини вичерпаються приблизно за 10-12 днів.
> * Крім того, GitHub забороняє тримати безперервні 24/7 процеси (daemon/loop).
> * IP-адреси дата-центрів GitHub іноді можуть потрапляти під жорсткі перевірки Cloudflare.
> 
> Якщо вам потрібен **цілодобовий щохвилинний моніторинг**, найкращий варіант — запустити скрипт локально на комп'ютері або на дешевому VPS ($3-5/місяць).

## 💻 Варіант 2: Безперервний запуск на своєму комп'ютері або VPS (24/7)

1. Встановіть Python 3.10+ (якщо ще не встановлено).
2. Відкрийте термінал у папці проєкту та встановіть залежності:
   ```bash
   pip install -r requirements.txt
   playwright install chromium
   ```
3. Запустіть скрипт у режимі постійного моніторингу (наприклад, кожні 60 секунд):
   * На Windows: двічі клацніть `run_local.bat` або виконайте:
     ```bash
     python check_queue.py --loop --interval 60
     ```
   * На Linux / VPS:
     ```bash
     python3 check_queue.py --loop --interval 60
     ```
   *(Можна також запустити у фоні через `nohup python3 check_queue.py --loop --interval 60 &` або як systemd service).*
